# LASER SNAKE: APPLE APOCALYPSE

Ретро-аркада на C++17 и SFML 2.6.2. Змейка собирает яблоки и отбивается от насекомых непрерывным лазерным лучом. Интерфейс оформлен как экран старого зелёного ЭЛТ-телевизора.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| Пробел (удерживать) | Непрерывный лазер с перезарядкой |
| P / Esc | Пауза |
| R | Начать заново |
| F11 / Alt+Enter | Полноэкранный режим |
| 1, 2 или 3 | Выбор улучшения после каждых 10 яблок |

## Игровые механики

- Два луча выходят из глаз змейки и проходят по соседним линиям перед ней.
- Лазер работает, пока удерживается пробел. Урон наносится при завершении перезарядки.
- В начале перезарядка короткая; с каждой волной она становится длиннее.
- Каждые 10 съеденных яблок игра останавливается и предлагает выбрать улучшение: ускорить перезарядку, восстановить жизнь или увеличить максимальное здоровье.
- Четыре противника: жук, богомол, оса и королева-богомол.
- Есть обычные и золотые яблоки, щит, ускоренная стрельба и удвоение очков.
- Добавлены звуки поедания, убийства, получения урона и непрерывный синтезированный звук лазера.
- Рекорд хранится в `highscore.txt`.

## Сборка на Windows

Проект использует CMake и автоматически загружает SFML 2.6.2. Для локальной сборки нужны C++17, CMake, Git и MinGW-w64 UCRT64. Также нужна библиотека OpenAL для звука.

```bash
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

## Сборка через GitHub Actions

В репозитории есть `.github/workflows/main.yml`. После push GitHub Actions соберёт Windows-версию. Готовый архив `LASER-SNAKE-Windows` находится в Artifacts завершённого запуска workflow.


## Исправления

- Русский шрифт DejaVu Sans Mono входит в комплект игры и копируется рядом с EXE.
- Лазер поражает ближайшего противника непосредственно впереди змейки на той же линии движения.
- Урон наносится один раз за цикл перезарядки, пока пробел удерживается.
