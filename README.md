# LASER SNAKE: APPLE APOCALYPSE

Небольшая аркадная игра на C++ и SFML 2.6.2. Змейка движется по клеткам, собирает яблоки и отбивается от насекомых двумя лазерами, которые вылетают из её глаз.

## Что есть в игре

- Клеточное управление с помощью WASD или стрелок.
- Два лазерных луча, стреляющих вперёд по направлению движения.
- Четыре противника:
  - **Жук** медленно преследует змейку.
  - **Богомол** быстрее жука и выдерживает два попадания.
  - **Оса** преследует змейку и стреляет зарядами.
  - **Королева-богомол** появляется на каждой пятой волне, имеет большой запас здоровья и атакует снарядами.
- Обычные и золотые яблоки.
- Три бонуса: щит, ускоренная стрельба и удвоение очков.
- Сложность постепенно растёт: противников становится больше, а они двигаются быстрее.
- Три жизни, пауза, перезапуск и экран окончания игры.
- Лучший результат сохраняется в `highscore.txt` в рабочей папке игры.
- Графика рисуется средствами SFML: отдельные картинки и дополнительные игровые ресурсы не нужны.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` или стрелки | Движение |
| `Space` | Стрелять лазерами (можно удерживать) |
| `P` или `Esc` | Пауза |
| `R` | Начать заново |
| `Enter` | Начать игру / продолжить после проигрыша |

## Сборка на Windows

Нужны **C++17**, **CMake**, **Git** и компилятор MinGW-w64. Проект сам скачает и соберёт SFML 2.6.2 через CMake, поэтому отдельно настраивать пути к библиотеке не придётся. Для первой сборки потребуется интернет.

1. Открой терминал MSYS2 UCRT64.
2. При необходимости установи инструменты:

   ```bash
   pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-make git
   ```

3. Перейди в папку проекта.
4. Запусти:

   ```bash
   ./build_windows.bat
   ```

После сборки игра запустится автоматически. Исполняемый файл будет находиться в папке `build`.

Можно выполнить сборку вручную:

```bash
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
./build/LASER_SNAKE.exe
```

## Сборка на Linux

Установи компилятор C++17, CMake, Git и системные зависимости SFML для графики. Затем запусти:

```bash
chmod +x build_linux.sh
./build_linux.sh
```


Папка `build` и файл личного рекорда не попадут в репозиторий: они уже добавлены в `.gitignore`.
